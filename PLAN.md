# PLAN — p9draw + desk

## Current Focus

**Графический терминал на homelab**: acme + терминал + браузер + вьюверы + shell до
системы (вызов агента включительно), доступный из браузера дома, на работе и позже
с телефона.

Основной трек — контейнер `desk` на **:3007** (стек linuxserver webtop / Selkies,
сессия **labwc**; лестница по факту захвата: labwc → icewm → sway). p9draw отдаёт
acme нативным Wayland-клиентом. Спецификация: `deploy/desk/`, база
`lscr.io/linuxserver/webtop:debian-xfce` (обвязка Selkies/s6/pulse доказана),
план9порт и бинарь p9draw — bind-mounts.

**Правило верификации:** только собственные скриншоты и пробы (headless Chrome по
CDP), отчёты моделей доказательством не считаются.

## Направления (зафиксированы 2026-10-04)

| Трек | Статус | Следующий шаг |
|---|---|---|
| **desk :3007** — основной | строится | спайк захвата labwc → icewm при неудаче; verify своим браузером |
| **waypipe** (`waypipe-test`, :2222) | работает, dev-режим | задокументировать подключение; инвестиций ноль |
| **webland :3030** | заморожен, R&D | late-join decode-баг: фоновая подсессия или апстрим-issue (патч и улики в репо) |
| **draw-canvas** (drawterm в браузере на p9draw) | отложено | после стабилизации desk; `p9draw-render` wasm-ready |
| **wio + prio/Arcan** | эксперимент | поиграть; форк Rubo3/wio жив (wlroots 0.19, 2025-06) |
| **телефон + auth** | pending | UX трёхкнопочной мыши; Keenetic https-поддомен для :3007 |

## Decisions (rationale)

| Решение | Почему |
|---|---|
| Заменить devdraw, не трогать acme | «Нас опередили трижды — и все застыли» (wl9, 9webdraw, plan9port-wayland #130); devdraw — отдельный процесс, acme работает как есть |
| p9draw на Rust, кирпич 1 | ~20% кайфа, дёшево; язык решён 2026-09-30 |
| Кирпич 2 (пиксельный libframe, cosmic-text) — позже | ~80% кайфа, дорого; встанет поверх стабильного стола |
| Кирпич 3 (мозг: Edwood vs C-acme) | осознанно не решён — после desk |
| Стриминг полного стола (Selkies), не per-window | универсальность: любые приложения, а не только draw-протокол; per-window живёт в webland R&D |
| Сессия: labwc → icewm → sway | title-бары и мышь-first (управление через видеопоток без клавиш); выбор по факту захвата Selkies |
| Контейнер, не хост/дистробокс | хост остаётся минимальным; дистробокс требует живого десктоп-сеанса хоста |
| Имя p9draw; ISC; github.com/e4779/p9draw | 2026-10-05; crates.io отложен (метаданные готовы) |
| pi-web (:8504) в браузере стола + ssh→pi | агент — часть стола; два пути на один хостовый агент |

## Constraints

- Проверка — своими глазами (скриншоты/пробы), не отчётами
- Хост минимальный: весь десктоп в контейнере; quadlet + keepalive обязательны
- Пара acme переживает смерть (keepalive не считает зомби живыми)
- Секреты не в git; RU-домены — без прокси
- История — в `docs/roadmap-devdraw.md`; PLAN не дублирует дневник
