# Overview

В acme встроен язык команд редактирования sam (структурные регулярные
выражения). Anvil расширяет идею до Range Statements: текущие выделения
окна — начальные диапазоны языка; выражения, порождающие диапазоны,
заменяют выделения. Цикл «выделить мышью → уточнить выражением → снова
мышью» становится тактильным.

# Details

- Пайплайн «выделение → команда» остаётся главным жестом (Unix-наследие).
- Range statements = декомпозиция сложности: сложное редактирование
  собирается из простых диапазонных шагов, а не из одного макроса.
