# Overview

Классический unix: работа на удалённой машине, терминал — локальное стекло
(ssh+tmux). Drawterm продолжает: сессия и рендер на сервере, по сети —
команды отрисовки. X задумывался сетевым, но стал «непрозрачным» — SHM/GLX
сделали сеть второстепенной дорогой. Спор approached three ways:

# Details

## Три школы (проверено экспериментами 2026-09)
1. Протокольная: waypipe (wayland-протокол по ssh, per-app окна,
   чувствителен к RTT).
2. Видео/per-surface: webland (H.264 на поверхность, WebCodecs,
   композиция в браузере; перемещение окна ничего не отправляет).
3. Per-window ssh: Anvil ([user@]host:/path — окно несёт свой удалённый
   контекст; удалённой стороне нужны только sh+cat).

## Цель грида
«ssh — шелл на другой машине под другой учёткой; между plan9-машинами
была бы одна учётка» — одна идентичность и одно пространство имён
(NAS CPU server + VPS через plan9port + ноутбук). Минимальный вариант:
wikifs-rs на hlab, примонтированный с ноута через plan9port (проверено
на ноуте в июне 2026).
